🎙️ AI Voice Language Tutor

An AI-powered voice language tutor that helps users practice speaking and improve their grammar through real-time voice interaction.

✨ Features

- 🎤 Speech-to-text using the browser's Web Speech API
- 🤖 AI-powered grammar and language feedback
- 🔊 Text-to-speech for spoken feedback
- 🌍 Multiple language options
- 💻 Simple and responsive user interface
- 🔐 API key protected using environment variables

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- OpenAI API
- Web Speech API

🚀 How It Works

1. Select a language.
2. Click **Start Speaking**.
3. Speak a sentence.
4. The browser converts your speech into text.
5. The backend sends the sentence to the AI.
6. The AI provides grammar feedback.
7. The feedback is displayed on the webpage.
8. The tutor can speak the feedback aloud.

⚙️ Setup

 1. Clone the repository

git clone https://github.com/sonubudharam92-star/AI-Voice-Language-Tutor

2. Install dependencies

npm install

3. Create the .env file

Create a .env file in the project root:

OPENAI_API_KEY=your_api_key_here

4. Start the server

node backend/server.js

Then open the application in your browser.
